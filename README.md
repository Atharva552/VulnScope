# VulnScope

A lightweight Vulnerability Assessment & Penetration Testing (VAPT) Scanner built with FastAPI and Nmap.

---

## Features

- Service Version Detection
- Nmap Integration
- SSL/TLS Certificate Analysis
- HTTP Security Header Analysis
- Scan History
- PDF Report Export
- JSON Report Export
- Dashboard
- FastAPI Backend
- Bootstrap UI

---

## Technology Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Nmap
- Jinja2
- Bootstrap 5

---

```
app/

```

---

## Installation

```bash
git clone https://github.com/Atharva552/VulnScope.git

cd VulnScope

pip install -r requirements.txt

uvicorn app.main:app --reload
```
