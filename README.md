# Basic VAPT Scanner

A web-based Vulnerability Assessment and Penetration Testing (VAPT) Scanner built using FastAPI.

## Features

- Host Discovery
- Port Scanning
- Service Detection
- HTTP Security Header Analysis
- Technology Detection
- Directory Enumeration
- Report Generation

## Tech Stack

- FastAPI
- Python
- SQLite
- SQLAlchemy
- Bootstrap
- AdminLTE
- Nmap
- FFUF
- WhatWeb
